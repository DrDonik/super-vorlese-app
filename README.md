# Super Vorlese-App

**Gemeinsam vorlesen — auch über weite Distanzen.**

Die Super Vorlese-App ermöglicht es mehreren Personen, gleichzeitig auf
ihren eigenen Geräten dasselbe Buch zu sehen und zusammen Seite für Seite
umzublättern. Wer jemandem über die Distanz hinweg vorlesen möchte —
Grosseltern dem Enkelkind, Eltern auf Reisen ihrem Kind zu Hause, Freunden
in einer anderen Stadt — kann es jetzt tun, als sässe man nebeneinander.

Die App ist bewusst so einfach gehalten, dass ein sechsjähriges Kind und
seine Grosseltern sie gemeinsam ohne fremde Hilfe bedienen können.

**Live ausprobieren:** [drdonik.github.io/super-vorlese-app](https://drdonik.github.io/super-vorlese-app)

## So funktioniert's

1. Startet einen Videoanruf nebenher (z. B. WhatsApp, FaceTime, Zoom)
   — nicht Teil dieser App.
2. Koppelt das gewünschte Buch einmalig mit einem sechsstelligen Code.
3. Wer eine Seite umblättert, blättert für alle mit.
4. Halte den Finger (oder die Maustaste) auf der Seite gedrückt, um den
   anderen zu zeigen, wo du gerade liest — der Punkt erscheint auch auf
   ihren Geräten.

## Was du brauchst

- Ein Gerät mit aktuellem Browser pro Person
- Ein Buch als PDF oder als Fotos (direkt in der App erstellt) auf einem der Geräte
- Einen separaten Videoanruf

## Technisches

Web-App auf Basis von Vite, Firebase Realtime Database, pdf.js und
